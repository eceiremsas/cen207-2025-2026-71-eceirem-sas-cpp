\doxysubsection{Detailed Description}
Min-\/\+Heap structure. 

Min-\/\+Heap implementation using a dynamic array (std\+::vector).

Array-\/based implementation of a complete binary tree. The parent node always has a smaller calorie value than its child nodes.

Maintains the heap property based on \doxylink{struct_recipe}{Recipe} calorie values.
