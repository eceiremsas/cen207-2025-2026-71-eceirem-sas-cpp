\doxysubsection{Detailed Description}
Represents a sparse matrix storing ingredient-\/recipe relationships. 

Represents a sparse matrix linking recipes and ingredients.

Implemented as a linked list of \doxylink{struct_matrix_entry}{Matrix\+Entry} nodes.

Each non-\/zero cell is represented as a \doxylink{struct_matrix_entry}{Matrix\+Entry} node.
