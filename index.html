🧮 Calculator App

Calculator Project Library Generation and Testing Template

C++ CMake GoogleTest Doxygen

📋 Genel Bakış

Bu proje, CMake ve CTest kullanımını gösteren bir modül paketi sağlar. Ayrıca Doxygen dokümantasyonu ve test coverage raporlarını birleştirir. Modern C++ geliştirme pratiklerini ve test odaklı geliştirme yaklaşımını gösteren kapsamlı bir şablon projedir.

🔧 Özellikler

  • CMake ile proje yönetimi
  • CTest entegrasyonu
  • Doxygen dokümantasyon
  • Test coverage raporları
  • Cross-platform desteği

🖥️ Platformlar

  • Windows
  • Linux (WSL)
  • macOS
  • Visual Studio desteği
  • Ninja build sistemi

📊 Raporlama

  • Test coverage raporları
  • Dokümantasyon coverage
  • Unit test sonuçları
  • HTML raporlar
  • Badge sistemleri

📦 Gereksinimler

  • CMake >= 3.12
  • C++ Standard >= 11
  • GoogleTest (test modülleri için)
  • Visual Studio Community Edition (Windows için)
  • Ninja (WSL/Linux için)
