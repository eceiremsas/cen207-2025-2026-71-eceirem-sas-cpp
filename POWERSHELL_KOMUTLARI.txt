POWERSHELL'DE KLASÖR TEMİZLEME VE BUILD KOMUTLARI
==================================================

1. KLASÖR TEMİZLEME:
   Remove-Item -Path "build_win" -Recurse -Force

   Veya kısa hali:
   rm -r -Force build_win

2. BUILD VE TEST:
   .\8-build-test-windows.bat

   Veya manuel build:
   mkdir build_win
   cd build_win
   cmake .. -G "Visual Studio 17 2022"
   cmake --build . --config Debug
   ctest -C Debug --output-on-failure

3. SADECE TEST:
   cd build_win
   ctest -C Debug --output-on-failure

ÖNEMLİ: PowerShell'de backtick (`) kullanmayın!
Komutları direkt yazın, markdown formatı değil.
